# Day 1 MERN Stack Internship Assignment

This repository contains my Day 1 internship assignment. The objective of this assignment was to practice modern JavaScript (ES6+) concepts and build a responsive front-end component using HTML and CSS.

## Tasks Completed

### Task 2.1 - JavaScript Data Processing

In this task, I worked with a mock JSON dataset containing user information. The data was parsed, filtered, cleaned, and transformed based on specific conditions.

#### Concepts Used

* JSON.parse()
* Arrow Functions
* filter()
* map()
* Object Destructuring
* Spread Operator
* Template Literals

#### Functionality Implemented

* Parsed raw JSON data into JavaScript objects
* Filtered active users above 18 years of age
* Removed extra spaces from user names
* Extracted only required fields (id, name, email)
* Generated a summary of valid user records
